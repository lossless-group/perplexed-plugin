## Why Care?

Two things that used to work in Perplexed had stopped, silently. Notes came back without images, and company notes came back without funding rounds. Neither raised an error, so the only symptom was a note that was quietly less useful than it should have been.

Both work again in 0.6.0. And the `## Screenshots` section that toolkit notes ask for, which was empty in nearly every note we'd ever generated, now has a command that fills it with the product's real screenshots.

## What's New?

- **Images are back.** Perplexity stopped returning images from its Sonar API. Perplexed now gets them from Perplexity's image search, at the same time as the written answer.
- **Fetch screenshots from website.** Searches only the site in the note's `url` for product screenshots and adds the largest under `## Screenshots`, each linked to its source page. It keeps any images already there, and uses the note's `og_image` when the site shows none.
- **Funding rounds arrive again.** Fireround is now asked for a company's rounds by exact domain, instead of by a text search that missed most companies.
- **Claude Opus 5.5 by default,** with Fable 5.1, Sonnet 5.5, Haiku 5.5, and Opus 4.8 to choose from.
- **No hangs.** Image search gives up after 30 seconds and the note is written without it.

## What Happened to the Images

Perplexity is retiring Sonar Chat Completions, and requests to it are now rewritten for its Agent API. The Agent API has no `return_images` option, so the images we asked for simply weren't returned. It does have an `image_search` tool, which Perplexed now calls directly, forcing the tool on and, for screenshots, limiting it to the product's own domain. We wrote the change up in our keeping-up post, *Perplexity Sonar Pro Images Deprecated*.

## Good to Know

- **Image search costs $2.50 per 1,000 calls** on your Perplexity key.
- ***Find images for selection* still returns no images.** It places images paragraph by paragraph, so it needs a rewrite for the new API rather than a swap. That's next.
- **Fireround doesn't cover every company.** Very small, very new, or long-acquired companies may still have no rounds; the run continues and a notice says so.
- **On the 5.x Claude models, thinking is always on** and the effort setting controls its depth.

## Under the Hood

- `src/services/imageSearchService.ts` — the `image_search` call on `https://api.perplexity.ai/v1/agent`, the 30-second timeout, and screenshot selection (at least 800 pixels wide, largest first).
- `src/services/siteScreenshotsService.ts` and `src/utils/screenshotsSection.ts` — the new command and the `## Screenshots` writer it shares, by convention, with Metafetch.
- `src/services/fireroundService.ts` — `companies/rounds` with `{ company: domain }` replaces `rounds/search`.
- `src/settings/PerplexedSettings.ts`, `src/modals/ClaudeModal.ts` — the Claude model list.
