# Pick the Model Before a Folder Run, Not After

## Why Care?

Some templates default to Sonar Deep Research, which is right for a long market profile and wrong for a folder of standards and specs. Deep Research takes minutes per note and costs more. Applying one note at a time already let you pick a model. Applying a whole folder didn't, so the batch quietly ran every note on Deep Research.

## What's New?

- The batch confirm dialog has a **Model** dropdown, preselected to the template's default. Choose Sonar Pro and every file in the batch runs on it.
- The progress notice names the model the batch is using.
- The confirm text no longer says every file "will hit Perplexity deep research", which was only true for some templates.

## Under the Hood

The single-file run passed `modelOverride` to `applyTemplate`; the batch never did. `applyTemplateBatch` now takes an optional `modelOverride` and forwards it per file. The model list moved out of `DirectoryTemplateRunModal` into `src/modals/perplexityModelChoices.ts`, so the two dialogs offer the same choices.
